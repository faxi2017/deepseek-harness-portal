默认插件

支持 dsh plugin --profile web add -w 包名、npx @deepseek-ai/dsh plugin --profile web add -w 包名、npm install 包名 和 HTTPS .tgz 插件包地址。所有格式都会安装到 DSH 的 web profile 并启用插件，不支持 -g、脚本、路径或其他 npm 参数。保存后新用户会自动安装并启用；清空或移除命令只改变默认配置，不卸载已有插件。

批量操作使用已保存的命令，逐个安装，成功后自动重启，会中断当前对话连接；停止的实例也会启动。用户的模型配置、工作文件和其他插件保留。单个插件安装最多等待 5 分钟，失败可单独重试。
